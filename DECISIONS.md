# DECISIONS.md

## 1. Why this ingestion strategy over the obvious alternative you rejected?

**Chosen:** Tiered escalation (Tier 0: API → Tier 1: static HTML → Tier 2: headless browser). Each tier is tried in order; escalation only happens when the cheaper method fails or returns empty.

**Rejected:** "Always run full headless stealth" — rejected because it's wasteful (Playwright has 10–20x the resource cost of a static HTTP request), exposes a larger detection surface than necessary (a real browser leaks more fingerprint signals than a clean HTTP client), and is slower (browser launch + navigation vs. a single HTTP GET).

The strategy pattern (`StaticFetchStrategy` / `BrowserFetchStrategy`) allows config-driven tier switching without code changes.

## 2. One trade-off made under the time limit, and what you'd do with a real week

The proxy pool (`proxyPool.js`) is a 2-entry stub with deterministic domain-to-proxy mapping, not a real residential/mobile pool. It proves the abstraction exists and the rotation-on-failure pattern works.

**With more time:** integrate a paid rotating residential proxy service (e.g., Bright Data, Oxylabs), add per-ASN reputation scoring so the pipeline avoids datacenter IPs that are already flagged, and implement proxy health monitoring alongside source health monitoring.

## 3. Where did you use AI tools, and what did you personally verify or change afterward?

- **Claude** was used to scaffold the BullMQ queue config, circuit breaker state machine, and the selector fallback/quarantine pattern.
- **AI-generated code was reviewed and modified:** failure thresholds in the circuit breaker were adjusted after testing against the sandbox's chaos toggle (the initial defaults opened the breaker too eagerly on transient 5% malformed responses).
- **AI was used for test scaffolding:** the TDD test structure was generated by AI, then the implementation was written to pass those tests.
- **No invented metrics:** all resilience claims in this document are backed by tests that run against the self-hosted sandbox. No detection-bypass rates are claimed for platforms we didn't test against.
